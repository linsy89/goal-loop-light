# goal-loop-light

把一句话的模糊委托，变成一个结构化、可执行的任务规划。

## 这是什么

给 AI 一个模糊任务（"帮我做一个调研""把这个功能优化一下""继续推进"），它容易跑偏——做着做着方向变了，或者一直在分析不产出，或者在应该问人的时候自己做了判断。

goal-loop-light 是一个轻量方法：在执行之前，先走 8 步推导，把"要做什么""什么算完成""不能牺牲什么""整个闭环需要什么资源""每一圈产什么""什么时候问人"都对齐清楚。对齐完成再执行，执行就不会迷路。

## 安装

把 `SKILL.md` 放到你用的 agent 的 skills 目录下。以 Claude Code 为例：

```bash
cp SKILL.md ~/.claude/skills/goal-loop-light/SKILL.md
```

也可以通过 settings 配置为 project-level skill。

## 用法

在你的 agent 里激活 goal-loop-light，然后给出模糊任务：

```
/ goal-loop-light

帮我把这个竞品调研推进完。
```

agent 会按 8 步推导走一遍，输出一个包含目标、成功标准、约束、阻塞扫描、持续推进策略的完整规划，并通过"请你确认/提供"等你回应。

**你需要做的：** 检查 agent 给出的澄清是否真正对准了你的意图。agent 擅长结构化提案，但只有你能判断方向对不对——这是人的判断力，不是 agent 能替代的。对齐后你就可以按规划手动推进。

适合哪些任务：
- 调研、分析、产品改进、代码重构——任何不是一轮能完成的事
- 你有模糊方向但还没厘清具体要做什么
- 你希望 agent 在动手前先把边界搞清楚

## 局限

当前版本聚焦在执行前的规划。规划完成后，每圈怎么自动推进、执行中怎么不丢失状态——是正在探索的方向。
